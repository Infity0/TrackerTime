# Time Tracker - Система учета рабочего времени

## Описание

**Time Tracker** — это веб-приложение для учета и анализа рабочего времени, построенное на Flask. Система позволяет пользователям отслеживать время, затраченное на различные задачи и проекты, с помощью удобного таймера и предоставляет детальную аналитику продуктивности.

## Основные возможности

### Управление временем
- **Интеллектуальный таймер** — запуск и остановка отслеживания времени с описанием задачи
- **Автоматический расчет** — точный учет продолжительности рабочих сессий
- **Привязка к проектам** — организация задач по проектам с цветовым кодированием
- **Московский часовой пояс** — корректное отображение времени для российских пользователей

### Управление проектами
- **Создание проектов** — настраиваемые проекты с описанием и цветом
- **Визуальная идентификация** — цветовые метки для быстрой ориентации
- **Гибкое управление** — добавление, редактирование и удаление проектов

### Аналитика и отчетность
- **Панель статистики** — обзор сегодняшней активности и общего времени
- **Детальные отчеты** — аналитика за выбранный период (7, 14, 30, 90, 180, 365 дней)
- **Визуализация данных** — графики и диаграммы распределения времени
- **Экспорт в CSV** — выгрузка отчетов для внешнего анализа

### Пользовательская система
- **Регистрация и аутентификация** — безопасный доступ к персональным данным
- **Изоляция данных** — каждый пользователь видит только свои проекты и записи
- **Сессии Flask-Login** — удобное управление авторизацией

## Технологический стек

### Backend
- **Python 3.7+** — основной язык разработки
- **Flask** — веб-фреймворк
- **Flask-SQLAlchemy** — ORM для работы с базой данных
- **Flask-Login** — управление аутентификацией
- **SQLite** — база данных (легковесная, не требует отдельной установки)
- **Pytz** — работа с часовыми поясами

### Frontend
- **HTML5** — семантическая разметка
- **CSS3** — современные стили с CSS переменными и градиентами
- **Vanilla JavaScript** — клиентская логика без зависимостей
- **Chart.js** — построение графиков и диаграмм
- **Адаптивный дизайн** — оптимизация для мобильных устройств

## Архитектура проекта

### Структура базы данных
- **User** — пользователи системы
- **Project** — проекты пользователей
- **TimeEntry** — записи рабочего времени

### Основные модули
- **app.py** — основной файл приложения с маршрутами и API
- **models.py** — модели базы данных и бизнес-логика
- **templates/** — HTML шаблоны с Jinja2
- **static/** — статические файлы (CSS, JS, изображения)
